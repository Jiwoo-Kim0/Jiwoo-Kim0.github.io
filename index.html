목표 순찰 로봇이 찾은 결함을 관리자가 위치·사진과 함께 바로 보고 처리 상태를 관리하게 합니다.

역할과 핵심 기여

  • 결함 API 11개 + 실시간 스트림(SSE) — 조회·상태 변경·병합·내보내기. 결함은 로봇이 보낸 관측으로만 생기게 해 관리자가 임의로 만들거나 지울 수 없게 했습니다.
  • 권한별 조회 범위 — 관리자는 배정된 로봇의 결함만 봐야 했습니다. 팀과 논의해 화면에서 가리는 대신 DB 조회 단계에서 걸렀습니다.
  • 결함 관제 화면 전체 — API를 부르지 않던 화면을 목록·필터·지도·상세 카드·상태 변경까지 실제 데이터로 연결했습니다.
    • 새 결함 알림이 오면 지금 보는 지도 밖일 때만 옮기고, 확대해 둔 화면은 되돌리지 않았습니다.
    • 묶음 확대는 누르면 같은 묶음이 다시 나오던 것을 고친 뒤, 팀원 피드백을 받아 누른 결함이 모두 담기는 만큼만 확대하게 한 번 더 고쳤습니다.
  • 증거 사진 업로드·조회 — 구현이 없어 항상 503이던 사진 조회를 새로 만들었습니다.
