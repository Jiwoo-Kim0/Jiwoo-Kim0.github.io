A무중단 배포 파이프라인

  • GitLab webhook → Jenkins → Build & Test → Deploy 구축 (deploy.sh 346줄)
  • 배포 전 사전 검증: 일회용 컨테이너로 기동을 확인한 뒤에만 운영 컨테이너 교체
  • 헬스체크 2단계 — readiness(DB·Redis 포함) + nginx 경유 end-to-end. MySQL을 docker pause해 두 체크가 다르게 반응함을 확인하고 분리

  • 효과: 이후 환경변수 누락·스키마 불일치 배포를 서비스 중단 없이 차단

  • 사용자별 호출 예산(시간당 40건) — Lua로 INCR+EXPIRE 원자화, Redis 장애 시 인프로세스 카운터로 전환

길봄 · 지도 묶음을 누르면 로그인이 풀리던 간헐적 장애
증상
결함 지도의 클러스터를 클릭하면 간헐적 401과 함께 로그인 화면으로 튕김
가설 1
동시 요청 20개 폭주 → 배치 조회 1회로 축소. 해결되지 않음
가설 2
인증 필터가 한 번의 거부로 세션을 삭제 → 수정했으나 거부 로그가 한 줄도 없었음. 헛다리
전환
추측을 멈추고 원인을 가를 수 있는 로그부터 심음 (sessionCookie/cookieValid/liveSession, 세션 삭제 트리거 RAISE LOG). 식별자는 남기지 않고 requestId로만 특정
원인
증거 이미지 API가 응답마다 새 세션 쿠키를 발급 → 동시 이미지 응답이 관리자 쿠키를 덮어쓰는 경쟁 조건
해결
분석과 로그를 공유해 Nginx 엣지 양방향 쿠키 차단 + 이미지 API 수정 + 엣지 계약 테스트를 각 담당자와 나눠 해결

증상

^~ /api/auth/로 걸었지만 실제 경로는 /api/v1/auth/
